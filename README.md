## A little about me

I'm an engineer who enjoys the whole journey from architecture to production: designing a platform, automating its delivery, understanding how it behaves under load, and fixing what breaks. My background combines cloud computing, DevSecOps, site reliability, software engineering, and data systems. I care about making complex systems dependable **and** understandable to the people who run them.

## What I do

- **Architect across environments.** Design multicloud and on-premises platforms, plan migrations, and build for availability, recovery, security, and sensible cost.
- **Build the platform beneath the product.** Run Kubernetes and container workloads; automate infrastructure and configuration; create CI/CD and GitOps workflows that teams can trust.
- **Keep production healthy.** Define SLIs and SLOs, build useful observability, investigate N3/L3 incidents, write runbooks, and automate away recurring toil.
- **Make security part of delivery.** Manage secrets and identities, add code and infrastructure checks to pipelines, and turn findings into practical fixes.
- **Connect infrastructure with data and AI.** Orchestrate data workflows, work with streaming systems, and apply machine learning to analytics and operational signals.
